# SwiftUI 版と AppKit 版の比較メモ

- 日付: 2026-11-06
- 比較元: `main` の AppKit 版（`7b232c9`）
- 確認環境: macOS（SDK 27.2）、Swift 6.4.2、Docker の PostgreSQL 17.11

## コード量

| | AppKit 版（`main`） | SwiftUI 版 |
|---|---|---|
| UI 層の行数 | 2,299 行 | 647 行 |
| 内訳 | `main.swift` 1,959、`ValueWindow.swift` 315、`CopyableTableView.swift` 25 | `AppModel` 321、`ContentView` 142、`GridLogic` 78、`DataGrid` 47、`SQLView` 31、`TypleDataViewerApp` 28 |

機能の範囲が違うので、行数は単純に比べられない。SwiftUI 版には、接続先の編集、外部キー移動、列の記憶、エクスポート、値ウィンドウ、状態復元、日英切替がない。

ただし、状態から画面への反映はかなり短くなった。AppKit 版の `updateDataControls` のように手で画面を更新する処理が要らず、`AppModel` の処理は読み込みとエラー処理が中心になった。

## うまくいった点

- **動的列の `Table`：** `TableColumnForEach` と `TableColumn(_:sortUsing:)` で、列が実行時に決まる表を約 50 行で作れた。仕様で未確認としていた見出しソートも、自前の `SortComparator`（`GridSort`）で動いた。代替 UI は要らなかった。
- **列名の重複：** 列の ID を位置にしたので、`SELECT a.id, b.id ...` も正しく表示できた。
- **共用：** データ、スキーマ、SQL の結果を同じ `DataGrid` で描けた。

## 作りにくかった点

いずれもビルドは通り、実機で初めて気づいた。

| 問題 | 対処 |
|---|---|
| ページ送りでスクロール位置が残り、新しいページの途中が表示された | `ScrollViewReader` で先頭へ戻した。AppKit 版は `scrollRowToVisible(0)` の1行 |
| `.fixedSize()` を付けた `Picker` とツールバーの `Picker` の幅がつぶれ、選択値が読めなかった | `.frame(width: 160)` で幅を固定した |
| `ContentUnavailableView` が広がらず、タブごと画面の中央へ寄った | `.frame(maxWidth: .infinity, maxHeight: .infinity)` を付けた |
| `ConnectionTarget` が `Hashable` でなく、`Picker` の値に使えなかった | `key` 文字列で束ねた |
| 既定のメニューが英語で表示された（`Edit`、`View` など） | 未対応。バンドルに日本語のローカライズがないため。AppKit 版はメニューを自前で作っている |

## 試していない点（外した機能）

次の機能は今回の範囲外で、SwiftUI の `Table` でどこまで作れるかは確かめていない。AppKit 版にある機能のうち、置き換えを考えるなら先に調べるべき部分である。

- セル単位の右クリックメニューとダブルクリック（値ウィンドウ、外部キー移動の入口）
- 列の並び、幅、非表示の保存（`TableColumnCustomization` が候補）

また、列の構成が変わると `.id(columns)` で表を作り直すので、ユーザーが変えた列幅はテーブルを切り替えると失われる。

## 1,000 行ページの操作感

2,500 行のテーブルを 1,000 行ずつ表示して測った（Debug ビルド、ローカル DB）。

| 項目 | 結果 |
|---|---|
| DB からの取得 | 約 20 ms |
| 結果の反映から、メインキューが2回りするまで | 12〜61 ms |
| スクロール（中央へのジャンプ）、行の選択 | 目立つ遅れなし |

反映の時間は計測用の一時コードで測った。描画の完了までを測ったものではない。スクロールと選択は自動操作での確認で、手でなめらかさを確かめたものではない。AppKit 版は同じ条件で測っていないので、速度の優劣は言えない。

## 実機で確認した内容

接続と切断、テーブル・ビュー・マテリアライズドビューの一覧、ページ送り、検索（全列）、見出しの並べ替え、NULL の斜体、数値の右寄せ、改行と長文の省略表示、0 行のテーブル、スキーマタブ、SQL の実行（「実行」ボタン）、SQL の初期文、列名の重複、列が0個の結果、書き込み文の拒否とアラート、再読み込み（メニュー）、行が減ったときの最後のページへの補正。

## 確認できなかった内容

- **`Cmd+C` のコピー：** 操作ツールの制限で実行できなかった。TSV の整形はテスト済みだが、`.onCopyCommand` が動くかは未確認。
- **TLS での接続：** テスト用 DB が TLS なしのため、確認の間だけ `Database.swift` の TLS を無効にした（コミットしていない）。TLS の処理は `main` と同じコード。
- **保存済み接続先の選択、絞り込む列の `Picker`、`Cmd+Return`、`Cmd+R` のキー操作：** 操作ツールで扱えない、または試していない。再読み込みはメニューから確認した。
- **読み込み中や SQL 実行中の切断、テーブル切り替え：** ローカル DB では読み込みが速すぎて再現できなかった。世代番号の処理は AppKit 版と同じ考え方。
